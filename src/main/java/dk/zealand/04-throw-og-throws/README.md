# 04 – Throw, throws og exception propagation

**Forudsig:** Hvilken metode kaster fejlen, og hvilken fanger den?

**Afprøv:** Følg `main() → runSimulation() → loadData()` i debuggeren.

**Ændr:** Fjern `throws IOException` fra `runSimulation()` og undersøg compilerfejlen. Sæt det derefter tilbage.

**Forklar:** Forskellen mellem `throw` (kaster) og `throws` (deklarerer).
