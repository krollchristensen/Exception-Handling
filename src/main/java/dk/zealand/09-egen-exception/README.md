# 09 – Egen checked exception

**Forudsig:** Hvilken ingrediens accepteres, og hvilken kaster en exception?

**Afprøv:** Kør `Main`.

**Ændr:** Tilføj en ekstra ingrediens, som afvises, og en `ArrayList` til godkendte ingredienser.

**Undersøg:** Ændr `InvalidIngredientException` til at arve fra `RuntimeException`. Hvad sker der, hvis du fjerner `throws`?

**Bemærk:** Dette er en kort demonstration. Den fulde Smoothie-opgave skal du selv løse.
