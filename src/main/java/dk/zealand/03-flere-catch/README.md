# 03 – Flere catch-blokke

**Forudsig:** Hvad sker der ved `abc`, `0` og `5`?

**Afprøv:** Kør programmet med hvert input.

**Ændr:** Tilføj `catch (IllegalArgumentException e)` **efter** `catch (NumberFormatException e)`.

**Undersøg:** Hvorfor vil det ikke compilere, hvis du sætter `IllegalArgumentException` først? (`NumberFormatException` arver fra den.)
